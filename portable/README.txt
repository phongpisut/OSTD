OSTD (portable)

1. Unzip this folder anywhere you can write to (Desktop, D:\Games\...). No install, no admin.
2. Run ostd.exe. The first launch picks a model that fits your GPU and downloads it.
3. Press Ctrl+Shift+T in a game, drag a box around the text (or click for the whole window).
   Press Ctrl+Shift+T again to stop. Click "Suggest" under the status pill for help with choices.

Everything stays in this folder:
  data\    settings, llama.cpp, logs
  models\  downloaded models (you can pick another folder in the setup window)

To move or back it up, copy the whole folder. To remove it, quit from the tray icon and delete the folder.
Games must run in borderless windowed mode.
